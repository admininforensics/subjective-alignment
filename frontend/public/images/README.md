# Brand images

## Login background

Place your login screen background image here:

```
frontend/public/images/login-background.jpg
```

Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`

The app looks for **`/images/login-background.jpg`** first. If that file is missing, it falls back to `login-background.png` or `login-background.webp`.

After adding the file, refresh the login page (no rebuild required for static files in `public/`).
